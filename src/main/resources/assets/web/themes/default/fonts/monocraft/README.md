# Monocraft

Monocraft by Idrees Hassan, version **4.2.1**, distributed under the SIL Open
Font License 1.1. The original copyright notice and license are included in
[`LICENSE`](LICENSE).

Upstream release: <https://github.com/IdreesInc/Monocraft/releases/tag/v4.2.1>

The bundled files are full WOFF2 conversions of these pinned upstream sources:

- `Monocraft-Regular.woff2` (weight 400):
  <https://github.com/IdreesInc/Monocraft/blob/v4.2.1/dist/Monocraft-ttf/Monocraft.ttf>
  — source SHA-256: `262e31822e0a75be567b02320bfa092143d871e8a273e529d1c5ab0c04cd215f`.
- `Monocraft-Bold.woff2` (weight 700):
  <https://github.com/IdreesInc/Monocraft/blob/v4.2.1/dist/Monocraft-ttf/weights/Monocraft-Bold.ttf>
  — source SHA-256: `d5b840fa300981271fbccb2385e27f61f4220c6a81b497e60ff582a2ede5ce99`.

Converted with fontTools 4.63.0 and Brotli 1.2.0 using `TTFont`, setting
`font.flavor = "woff2"` before saving. No glyph subsetting or design changes were
applied. Both files retain all 1,700 glyphs and the original character mappings,
including the complete Polish alphabet.
