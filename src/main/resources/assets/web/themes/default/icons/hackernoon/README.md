# HackerNoon Pixel Icon Library

Pixel icons by HackerNoon, distributed under the [MIT license](LICENSE).

The inline SVG in `info-circle.mjs` uses the original 24 × 24 geometry from
[`info-circle.svg`](https://github.com/hackernoon/pixel-icon-library/blob/fa562540941211a9f7e2fb236b9cbd40810d95f1/icons/SVG/regular/info-circle.svg).
The theme renders it as a filled blue circle with a white information symbol.

`terminal.mjs` contains the original 24 × 24 geometry for these
[regular icons](https://github.com/hackernoon/pixel-icon-library/tree/fa562540941211a9f7e2fb236b9cbd40810d95f1/icons/SVG/regular):

| Icon            | Use                                     |
| --------------- | --------------------------------------- |
| `grid`          | All resources                           |
| `archive`       | Stored resources                        |
| `cog`           | Craftable resources and crafting marker |
| `tag`           | Sort by name                            |
| `numbered-list` | Sort by quantity                        |
| `hashtag`       | Sort by registry ID                     |

The theme adds colored interior fills to the terminal icons; the original pixel outlines are retained.
