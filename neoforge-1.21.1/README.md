# AE2 Web Integration — Minecraft 1.21.1

This directory contains the NeoForge 1.21.1 adapter for AE2 Web Integration.

Shared code is in [`../core`](../core); see the [project documentation](../README.md).
Run `./gradlew :neoforge-1.21.1:build` from the repository root to build this adapter and package shared core without running core tests.

Installable JARs are available on the [Releases page](https://github.com/kuba6000/AE2-Web-Integration/releases).
