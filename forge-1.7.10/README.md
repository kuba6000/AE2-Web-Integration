# AE2 Web Integration — Minecraft 1.7.10

This directory contains the Forge 1.7.10 adapter for AE2 Web Integration, targeting the GTNH forks of AE2 and
AE2FluidCraft.

Shared code is in [`../core`](../core); see the [project documentation](../README.md).
Run `./gradlew build` from this directory to build the adapter and shared core together.

Installable JARs are available on the [Releases page](https://github.com/kuba6000/AE2-Web-Integration/releases).
