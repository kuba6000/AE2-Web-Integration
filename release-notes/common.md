<sub><strong>Telemetry is enabled by default.</strong> To help understand usage across mod and Minecraft
versions, packaged builds send a small HTTPS report after startup and approximately once per hour:
mod and Minecraft versions, public-mode and singleplayer flags, a random session ID renewed at each
server start, and a freshly salted proof used to recognize official mod JARs. Reports contain no
player names or UUIDs, world or network contents, or persistent installation ID.</sub>

<sub>Disable it with <code>/ae2webintegration telemetry off</code>, or set <code>enabled = false</code>
under <code>[telemetry]</code> in <code>config/ae2webintegration/config.toml</code> and reload the
configuration. See the <a href="https://ae2web.kuba6000.pl/privacy">privacy policy</a> for data handling
and retention.</sub>
