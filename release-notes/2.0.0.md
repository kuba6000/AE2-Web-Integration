## AE2 Web Integration 2.0.0

A redesigned web interface, live storage and CPU views, resource history and a personal dashboard.
These are the changes since **1.2.0-pre**. The main mod still only needs to be installed on the server.

### New web interface

- Responsive desktop and mobile layouts, including redesigned login and registration.
- Light, dark and system appearance; **Monocraft or Lato** fonts.
- Names, icons or both, with configurable columns and page size, including no pagination.
- Resource details, context menus, custom tooltips and remembered display preferences.
- Colored, dismissible notifications for actions and errors.

### Live terminal and CPU views

- Storage and selected CPUs **update live**, with automatic reconnection if the connection drops.
- Resource amounts update without constantly rearranging the list.
- See crafting progress, time spent and estimated production rates where tracking is available.
- See what busy CPUs are crafting and whether they accept player or automated requests, including supported AdvancedAE CPUs.
- Turn automatic updates on or off in Web Settings.

### Resource tracking

- Track stored quantities and resources entering or leaving each network, with totals and transfer counts.
- See the last two minutes of flow and one hour of stock changes in tooltips and resource details.
- Explore history with interactive charts: zoom in, select a point and choose which lines to display.
- Choose pixel or smooth chart styles.
- Set how often each network records measurements and how long it keeps history, within the server's limits.

### Pins and Home

- Your terminal pins stay at the top regardless of search and filters, with a separate order for each network.
- **Home cards** combine pinned resources from multiple networks, with configurable charts and summaries.
- Pins keep access to recorded history when resources disappear from storage.

### Crafting

- Clearer plans and CPU layouts for missing ingredients, storage requirements and resource states.
- **PNG plan export** with configurable layout, ordering, contents and background.
- Completed and cancelled jobs remain in history after a server restart, with resource totals, timings and machine details.
- See who requested a craft, including player, machine and web requests combined into one job.
- Choose whether to include machine-requested crafts and how long to keep each network's history.
- Lite crafting, ignore-missing, pause and selection controls where supported by the installed AE2 version.

### Icons and themes

- Optional **item and fluid icons** exported from your modpack and resource packs.
- Generate icon packs with a separate client tool, then install them on the server.
- Install custom **ZIP themes** on the server and choose a default, or pick your own theme in the browser.
- Recover the built-in interface with safe mode if a custom theme stops working.
- Documentation and a complete example project for creating your own theme.

### Login and administration

- **Remember me** keeps you signed in across server restarts.
- Change supported options in **Server Settings** and apply them without restarting the server.
- Sensitive settings stay in the configuration file; administrators can disable the web settings editor.
- Keep, replace or clear notification credentials without exposing saved passwords or webhook URLs.

### Notifications

- Discord crafting cards, compact item thumbnails or plain-text notifications.
- Discord and ntfy notifications show the network name and who requested the craft.
- Configure notifications through Server Settings. Crafting notifications remain available only in private mode.

### Saved data

- Network settings, histories and pins are now saved in a **SQLite database** within the world folder.
