## AE2 Web Integration 2.0.0

A major update focused on a redesigned web interface and a clearer view of what is happening
inside your ME networks.

### Highlights

- **New web UI:** refreshed terminal, navigation and crafting views, with a layout that adapts to
  desktop and mobile screens.
- **Item tracking:** follow stock levels and item flow over time, with history charts for the
  resources you want to monitor.
- **Crafting visibility:** inspect active jobs and completed crafting history from the web panel.
- **Optional item icons:** use the standalone client icon generator to create an icon pack for
  your modpack and resource packs.
